# Unity-RPG-2D
这是我学习unity的项目
一款基于 Unity引擎 开发的 2D 角色扮演游戏，核心玩法包含地图探索、即时战斗、角色成长与背包系统，旨在构建一个完整且可玩的游戏世界。
角色控制系统：
设计并实现了基于 C# 的角色移动、动画状态机（如Animator Controller管理Idle、Run、Attack动画）以及碰撞交互逻辑，确保了角色操作的流畅性与反馈的准确性。
战斗系统开发：
主导了战斗系统的架构与编码。利用ScriptableObject设计可灵活配置的敌人数据与技能效果，实现了战斗逻辑与数据的分离，提升了系统的可扩展性。
UI框架与数据管理：
构建了游戏内主要的UI界面（如主菜单、角色背包、制作系统）。
性能与体验优化：
针对2D游戏特点，通过对象池技术优化了频繁生成的粒子特效或子弹，减少了运行时开销。同时，优化了场景资源加载逻辑，有效避免了游戏卡顿。
